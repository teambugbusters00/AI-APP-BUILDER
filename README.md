# AI App Builder Blueprint Generator

FastAPI endpoint that turns a structured app specification into a project structure, milestone plan, and security checklist.

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open /docs. Generated plans are suggestions; review architecture, threat model, and requirements before implementation.

## Live deployment

- **Frontend:** https://ai-app-builder-frontend-vijayjangids-projects.vercel.app
- **Backend API:** https://ai-app-blueprint-api.onrender.com
- **API docs:** https://ai-app-blueprint-api.onrender.com/docs

> Deployment is an MVP. Configure required secrets (if any), add authentication, and use durable database storage before production use.
